# Talk docs

What we decide together, away from the code and from the build guides.
Plans and idea lists live here; how a part works stays in `docs/world-kit.md`,
`docs/kit-work/` and `docs/map-work/`.

- `ideas.md` — every idea for the game, as a to-do list. Tick a box when done.
- `come-back.md` — the plan for the one thing the game lacks: a reason to play
  again tomorrow (ticket AWP-3, October 2026).
- `farm-life.md` — his own cattle, a bicycle of his own, building at home and
  giving his garden's fruit (the player's ideas of 12 October 2026).
- `build-plan.md` — gather Khmer materials, then build and decorate a home on
  a private plot (design chat of 13 October 2026; tickets AWP-5 to AWP-27).

A new plan or discussion goes in this folder, named after what it is about.
