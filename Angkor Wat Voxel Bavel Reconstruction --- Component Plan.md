game/interactive temple-selection scene.

**Important:** Treat this as a component plan, not as one giant
reference image. Each numbered component should later receive its **own
dedicated reference image**.

# 24 --- REFERENCE IMAGE RULE

Every generated reference image should follow the same visual rules:

-   Voxel 3D architecture
-   Angkor Wat proportions and Khmer architectural language
-   Orthographic/isometric presentation when possible
-   Neutral studio lighting
-   Clean background
-   No characters unless scale reference is explicitly requested
-   No modern buildings
-   No modern roads
-   No random fantasy architecture
-   Show the entire requested component
-   Include front / side / rear views when useful
-   Include a top view when the component has important footprint
    geometry
-   Include a small human scale reference only when dimensions matter
-   Keep materials consistent across all images
-   Keep the same voxel scale across the whole project

# 25 --- IMPORTANT ACCURACY NOTES

Angkor Wat's main complex and moat form a large rectangular composition
of approximately **1,500 m × 1,300 m**, with a moat approximately **190
m wide**. APSARA identifies the central pyramidal structure and its
**five interlocking towers** as defining features.

The temple was built in the **12th century during the reign of King
Suryavarman II**.

The real monument contains much more architectural and sculptural detail
than should be attempted as individual voxel objects. For the game,
prioritize:

1.  Correct overall proportions
2.  Correct spatial hierarchy
3.  Correct tower arrangement
4.  Correct galleries/enclosures
5.  Correct causeway and moat
6.  Recognizable Khmer architectural details
7.  Reusable voxel modules
8.  Surface detail last
